# Statistics-only handoff and continuation policy

User authorization (2026-09-10): handoff outputs must be statistics-only .txt, each smaller than 90 KB, with an explicit reading directory. Completed tests and downloads must not be repeated. This changes persistence and orchestration only; model inputs, generation, scoring, sampling, collection eligibility and training losses remain unchanged.

All portable results go into LATEN_STORE/STATS_TXT. Files are UTF-8, <=88,000 bytes including headers. Read 00_README.txt, then 01_INDEX.txt. The index lists byte counts and SHA256 of every statistics part, categories and reading order. No prompts, questions, reference answers, predicted answers, code solutions, token IDs, reasoning, sample-level traces, tensor assets or raw exception strings are included. Reports aggregate accuracy/counts, full LATEN/CF metrics and stratifications, complete-path Token/latent/prefill/byte counters, training steps/losses, collect gate counts, stage failure types, and recorded scheduler attempt durations. Section 09 includes only ended attempts actually present in the local journal; missing history is not reconstructed.

Runtime assets remain local: downloaded model/data files, training tensors and targets, optimizer checkpoints, identity manifests and minimal resumable score journals. These are necessary to continue training and are NOT deliverables. New evaluation journals store only scoring statistics and local bit vectors needed for CF aggregation. New general-task unscored text is not persisted; a process interrupted before committing its score may regenerate that unfinished sample. Existing completed scores and old unscored generations are read without re-running completed samples. Existing historical raw files are not deleted and are never included in STATS_TXT. Model-generated training targets remain in private training tensor assets because the unchanged training algorithm needs them; they are not evaluation output or handoff material.

Known 471c487 execution identity remains valid after verifying unchanged compute/data/metric core sources; known 3272ff7 training-free identities are still reconstructed and verified. A mere logging update does not reset training, collection or evaluation. Unknown remote source/config mismatches stop without overwriting old data. One-click resume first validates local environment/assets; verified downloads bypass network/setup and verified completed reference tests bypass execution. Missing assets alone are prepared. Completed evaluation cells and valid old smoke results allow smoke to be skipped. Model-scale selection must use --family explicitly.

Statistics export works offline with system Python and no GPU through bash run.sh export-txt (also status/report). Each refresh atomically replaces generated TXT parts under a dedicated lock, writes the index last, and removes only stale generated TXT parts. It never scans or packages arbitrary old files. Local CPU tests check byte limits including Chinese text, split reconstruction, complete indices, forbidden field exclusion, old-result aggregation, independent branch continuation and zero-call reuse of completed work. Target B200 performance remains unverified by these local checks.
